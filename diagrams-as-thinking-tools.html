Diagrams as thinking tools

2026-03-07

Writing is linear. Thinking is not. Sometimes the relationship between ideas is spatial — a flow, a hierarchy, a cycle — and no amount of prose can capture it as clearly as a diagram.

This is why embedding drawings alongside text matters. Not as decoration, but as a thinking tool. A diagram in the middle of an essay isn't an illustration — it's an argument made visible.

When to draw vs. when to write

Not everything needs a diagram. A good rule of thumb:

  • Write when the idea is sequential — arguments, narratives, instructions
  • Draw when the idea is relational — systems, flows, hierarchies, comparisons
  • Both when the idea has layers — a high-level visual with detailed prose explaining each component

The best technical documents alternate between text and diagrams like a conversation between two modes of thought.

Common diagram types

TypeBest forExample
FlowchartProcesses, decisionsDeploy pipeline

Mind mapBrainstormingFeature exploration

Each type optimizes for a different kind of clarity. A flowchart makes sequence obvious. An architecture diagram makes boundaries obvious. Choose the type that highlights what matters most.

SVG as the universal format

When drawings are published, they export as inline SVG — not rasterized images. This matters:

<!-- SVG scales to any size, supports dark mode, and loads instantly -->
<svg viewBox="0 0 800 600" class="drawing-embed">
  <rect x="100" y="50" width="200" height="80" rx="8"
        fill="var(--surface)" stroke="var(--border)" />
  <text x="200" y="95" text-anchor="middle"
        fill="var(--text)">Frontend</text>
</svg>

Because the SVG uses CSS custom properties (var(--surface), var(--text)), the diagram automatically adapts to the page's color scheme. Dark mode? The diagram goes dark. No separate assets, no color mismatches.

A note-taking app without drawing support is like a notebook where you can only write in straight lines. Sometimes you need to sketch, connect, circle, and arrow your way to understanding.
