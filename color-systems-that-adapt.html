Color systems that adapt

2026-03-07

A single hex value can generate an entire color palette. This is not a theoretical exercise — it is how modern design systems work. Given #3b82f6, you can derive 10 shades, 3 semantic colors, and both light and dark themes without touching a color picker.

Perceptual uniformity

The HSL color model is a lie. Moving the lightness slider from 50% to 60% does not produce a perceptually equivalent step across different hues. A yellow at 50% lightness looks dramatically different from a blue at the same value. This is why most auto-generated palettes look muddy or unbalanced.

The solution is to work in OKLCH — a perceptually uniform color space where equal numeric steps produce equal visual steps:

:root {
  --accent-base: oklch(0.65 0.18 250);
  --accent-light: oklch(0.80 0.12 250);
  --accent-dark: oklch(0.45 0.20 250);
  --accent-surface: oklch(0.95 0.03 250);
}

This gives us a palette where every shade feels intentional, because the math is the intention.

Dark mode is not an inversion

The most common mistake in dark mode implementation is inverting the palette — swapping white for black and calling it done. Real dark themes require:

  1. Reduced contrast — Pure white text on pure black is harsh. Use #e0e0e0 on #1a1a1a instead.
  2. Desaturated colors — Saturated hues glow on dark backgrounds. Pull chroma down by 15–20%.
  3. Elevated surfaces — Without shadows (which are invisible on dark), use subtle lightness variations to create depth.
  4. Dimmed images — Photos at full brightness are jarring. Apply filter: brightness(0.85) or opacity: 0.9.

Dark mode should feel like turning down the lights in a room — not like entering a cave.

Surface hierarchy

In a dark theme, depth is communicated through lightness, not shadow:

LayerLight modeDark mode
Base#ffffff#1a1a1a
Surface#f8f8f8#242424
Elevated#f0f0f0#2e2e2e
Overlayrgba(0,0,0,0.05)rgba(255,255,255,0.05)

This creates a visual stack that feels natural in both modes without relying on box-shadow — which disappears against dark backgrounds anyway.

Implementation in practice

Here's a minimal theme toggle using CSS custom properties and a single class on the root:

const toggle = document.querySelector('.theme-toggle');
const root = document.documentElement;

toggle.addEventListener('click', () => {
  const isDark = root.classList.toggle('dark');
  localStorage.setItem('theme', isDark ? 'dark' : 'light');
});

The toggle is instant because all the work is done in CSS — the JavaScript just flips a class. No re-renders, no FOUC, no layout shift.

Color is the most emotional axis of any design system. Get it right and the user never notices. Get it wrong and nothing else matters.
